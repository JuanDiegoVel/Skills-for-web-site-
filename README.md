🎬 Scroll Cinematic Landing

Skill para crear landing pages de una sola página con animaciones cinematográficas controladas mediante scroll, inspiradas en la estética visual de Apple y Republic of Gamers (ROG).

Permite construir páginas de presentación para videojuegos, productos, proyectos y portafolios con transiciones visuales fluidas, efectos de profundidad y narrativas dinámicas.

✨ Características principales

* Hero cinematográfico: portada que se expande progresivamente hasta ocupar toda la pantalla.
* Scrollytelling: escenas visuales que se desarrollan a medida que el usuario hace scroll.
* Paneles dinámicos: bloques de texto que aparecen desde la parte inferior y cubren las imágenes.
* Texto animado: despliegue de palabras sincronizado con el desplazamiento.
* Contadores animados: cifras que aumentan progresivamente al entrar en pantalla.
* Carrusel automático: transición de imágenes cada 5 segundos, con controles de pausa.
* Ciclo día y noche: transición visual entre el día y la noche controlada por el scroll.
* Animaciones reversibles: los efectos se repiten al regresar a las secciones.
* Diseño minimalista: tipografía, colores y composición inspirados en Apple y ROG.

🛠️ Tecnologías

* HTML5
* CSS3
* JavaScript Vanilla
* Intersection Observer API
* CSS Animations
* Scroll-based animations

No requiere frameworks ni librerías externas.

🚀 Instalación y uso

1. Descarga o incorpora este skill en tu entorno de trabajo.
2. Asegúrate de que el archivo SKILL.md y la carpeta assets/ mantengan su estructura.
3. Utiliza el skill cuando necesites desarrollar una landing page con animaciones cinematográficas.
4. Parte siempre de assets/template.html para conservar el sistema de animaciones.
5. Personaliza los textos, imágenes, colores y secciones según el proyecto.
6. Exporta el resultado como un archivo HTML independiente.

🎨 Sistema visual

El diseño utiliza una estética minimalista y tecnológica:

Elemento	Configuración
Fondo principal	Negro #000000
Superficie secundaria	#1d1d1f
Texto principal	#f5f5f7
Texto secundario	#86868b
Azul principal	#0071e3
Tipografía	SF Pro / Helvetica Neue
Navegación	Barra fija translúcida

La identidad visual puede adaptarse a la marca o proyecto correspondiente.

⚙️ Consideraciones

* Diseñado principalmente para navegadores de escritorio.
* Resolución de referencia: 900 px de ancho o superior.
* Respeta la preferencia prefers-reduced-motion.
* No utiliza recursos externos por defecto.
* Las imágenes reales deben incorporarse localmente o mediante URI data:.
* Los textos y datos de ejemplo deben sustituirse por información real del proyecto.

📌 Casos de uso

Este skill está pensado para desarrollar:

* Landing pages de videojuegos.
* Presentaciones de productos tecnológicos.
* Portafolios interactivos.
* Páginas promocionales.
* Presentaciones de proyectos universitarios.
* Experiencias web de tipo scrollytelling.
